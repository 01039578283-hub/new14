## 변경 범위와 결과

- 기존 제목 앞부분을 보존하고 ` | ` 뒤 접미사를 본문 기반으로 변경했다. 기존 OG/Twitter 제목도 함께 맞췄다.
- 제목 전체는 3,720개 모두 서로 다르다. 접미사는 752개 조합이며 제목 길이는 26~49자다.
- 본문 주제가 같은 페이지는 접미사가 같을 수 있다. 접미사의 완전 중복 제거를 위해 본문에 없는 학습법을 배정하지 않는다.
- H1, 본문, FAQ, 후기/상담 상황, 이미지·ALT·대표 이미지 숨김 속성, 목차, URL, canonical, robots, JSON-LD, 인증 태그, CSS/JS는 그대로 유지했다.
- 보호 HTML 6개는 수정하지 않았다. 사이트맵 3,725개 URL도 그대로 유지했다.
- RSS 14개 항목 중 대상 카테고리 10개 제목만 동기화했다. 나머지 제목, 링크, 설명, 날짜는 그대로다.

## 접미사를 고르는 근거

1. 초등·중등·고등 영어/수학 2,226개: 기존 본문 도입부가 명시한 핵심 학습 초점을 읽는다. 초등 원고의 문장 구조 차이도 처리하며, 학년·과목에 맞지 않는 키워드와 등록 안내는 제목으로 옮기지 않는다.
2. 영수학원 371개: 실제 요약문과 학습 본문에서 영어와 수학의 학습 항목을 하나씩 고른다. 기존 원고의 구체적인 진단 질문과 활동 문구를 근거로 삼고, 양 과목에서 똑같이 쓰는 모호한 문장만으로 과목을 판단하지 않는다. 공통 도입문만 반복되지 않도록 본문에서 뒷받침되는 구체적인 활동도 비교한다.
3. 국영수학원 1,113개: 학습 본문에 실제 등장하는 과제를 추출하고, 같은 카테고리에서 흔한 공통 안내의 비중을 낮춰 두 주제를 선택한다. 제목을 무작위로 순환하거나 지역명 해시로 선정하지 않는다. 초등 페이지에 수능·모의고사 같은 상위 단계 표현을 넣지 않는다.
4. 카테고리 10개: 각 카테고리 소개 문단에서 확인되는 주제만 요약한다.

예: `명일동 고등 수학학원 | 오답 원인·재풀이와 수학 학습 루틴 점검`

## 검증과 재실행

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONDONTWRITEBYTECODE = '1'
python -m unittest discover -s tools -p test_title_suffixes.py -v
python tools/personalize_title_suffixes.py --check
python tools/verify_title_release.py
python tools/verify_title_release.py --public
```

- 단위/회귀 검사 26개 통과.
- 전체 3,720개 타이틀, 실제 본문 근거와 고정 Git 기준의 제목 외 바이트 보존을 검증한다.
- 상세 3,710개 목차는 현재 HTML에 대해 구조를 검증한다. 이번 작업에서 목차 생성기로 본문을 다시 쓰지 않았다.
- `tools/reports/title-suffix-audit.json`에 전후 제목, 정확한 본문 근거, 선정 모드와 보존 해시를 기록했다.
- `tools/reports/title-suffix-local-verification.json`은 로컬 전체 검사 결과다. 공개 HTTP 결과·배포 준비 결과·배포 영수증은 같은 폴더의 Git 무시 보고서로 보관한다.
- 모든 `tools/` 파일과 환경 설정/내부 메타데이터는 Vercel 공개 업로드에서 제외한다.

기존 실행 명령 `python scripts/update_title_suffixes.py`도 새 개인화 생성기로 연결해 예전 공통 접미사로 되돌리지 않도록 했다. `--check`를 전달하면 수정 없이 재현성을 검사한다. 기본 `--write`는 제목과 대상 RSS 제목만 갱신한다.

본문을 의도적으로 새로 생성한 다음에는 원고 전용 검증을 먼저 실행하고 제목을 마지막에 적용한다. 일부 기존 원고 검증기는 과거 공통 접미사를 전제하므로, 최종 제목 검증에는 위의 전용 검증기를 사용한다. 본문 변경 후 고정 기준 커밋 비교가 실패하면 실제 변경 범위를 먼저 검토하고 승인된 기준을 갱신해야 한다.

최종 Git SHA, Vercel 배포 ID 및 실제 도메인 확인 결과는 배포 후 `tools/reports/title-suffix-release.json`에 남긴다. 검색 결과의 표시 제목은 검색 서비스가 별도로 선택할 수 있으므로 노출 문구나 순위를 보장하지 않는다.
