수학 서술형 답안에서 조건과 식의 근거와 결론을 연결하는 방법을 안내합니다.

작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

읽는 사람이 풀이의 연결을 따라갈 수 있도록 쓰세요. 문제의 조건, 사용한 성질, 계산, 답의 의미를 구분하면 생략한 근거를 찾기 쉽습니다.

현재 상태 확인

  • 문제 조건을 실제 풀이에 사용했나요?
  • 식이 바뀐 핵심 줄에 이유가 있나요?
  • 최종 답에 단위와 적용 조건이 있나요?

실행 순서

  1. 요구 확인하기

    설명·증명·계산 중 무엇을 요구하는지 읽습니다. 학교가 제시한 답안 형식이 있으면 함께 확인합니다.

  2. 풀이 뼈대 쓰기

    조건→사용할 성질→계산→결론의 순서를 먼저 적습니다. 필요 없는 문제 문장 전체를 복사하지 않습니다.

  3. 근거 덧붙이기

    식이 바뀌거나 관계를 얻은 지점에 짧은 이유를 씁니다. 그림을 썼다면 문자와 조건을 표시합니다.

  4. 다른 사람이 읽기

    풀이를 가리고 조건에서 결론이 이어지는지 읽어봅니다. 대입이나 단위 검토 결과를 마지막에 남깁니다.

연습 예시

연습 예시: 직사각형의 가로가 5cm, 세로가 3cm이면 “직사각형의 넓이는 가로×세로이므로 5×3=15cm²이다”라고 씁니다. 15라는 숫자만 쓰면 무엇을 구했는지 드러나지 않습니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.
