작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

제출 날짜만 적지 말고 자료 찾기·초안·수정·완료의 단계를 나누세요. 안내의 필수 조건은 마지막 검토 목록에 옮겨 빠진 부분을 확인합니다.

현재 상태 확인

  • 실제 평가 안내를 가지고 있나요?
  • 자료와 초안의 중간 확인 시점을 정했나요?
  • 출처와 파일 형식과 제출 방법을 확인했나요?

실행 순서

  1. 조건 옮기기

    주제·필수 항목·분량·기한·협업 규칙을 안내에서 옮깁니다. 없는 조건은 학교에 확인합니다.

  2. 작업 나누기

    자료 찾기→구성→초안→검토→제출로 나누고 각각 남길 결과를 적습니다.

  3. 중간 확인하기

    자료의 출처와 초안의 내용 누락을 먼저 봅니다. 꾸미기에 앞서 요구에 답했는지 확인합니다.

  4. 제출 전 검토하기

    필수 항목·출처·파일·제출 경로를 대조합니다. 제출한 경우 실제 확인 방법을 학교 안내에서 찾습니다.

연습 예시

연습 예시: 발표 과제라면 자료 목록, 말할 내용의 순서, 초안, 발표 연습을 각각 일정에 적습니다. 실제 주제와 시간·배점은 학교 안내에서 확인하며 예시 조건을 그대로 쓰지 않습니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.

놓치기 쉬운 점

협업과 AI 사용은 과제의 허용 범위를 따릅니다. 다른 사람의 결과물을 자신의 수행으로 제출하지 않습니다.

다음 확인
