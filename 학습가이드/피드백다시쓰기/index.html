작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

피드백을 읽은 것과 사용한 것을 구분하세요. 무엇을 고쳐야 하는지 자신의 말로 적고 원래 답안과 수정한 답안을 비교합니다.

현재 상태 확인

  • 피드백이 지적한 구체적 부분을 찾았나요?
  • 바꾸라는 내용과 이미 잘한 내용을 구분했나요?
  • 수정 이유를 새 과제에도 적용하나요?

실행 순서

  1. 원래 답 보존하기

    답안과 받은 피드백을 남깁니다. 수정 전에 어떤 부분이 부족했는지 표시합니다.

  2. 요구 되말하기

    근거 추가·조건 확인·계산 수정 등 해야 할 행동으로 바꿔 적습니다. 모호한 피드백은 질문합니다.

  3. 수정하고 비교하기

    필요한 부분을 고치고 전후의 차이와 근거를 씁니다. 전체를 새로 베끼는 것으로 끝내지 않습니다.

  4. 새 과제 확인하기

    비슷한 요구의 다른 과제에서 같은 기준을 적용합니다. 여전히 어렵다면 도움의 종류를 다시 정합니다.

연습 예시

연습 예시: “비교 기준이 없다”는 피드백이면 원래 답안에 공통 기준을 넣고 두 대상을 그 기준으로 비교합니다. 새 질문에서도 기준을 먼저 적어보며 수정 문장만 외우지 않습니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.
