학습 계획의 실제 결과와 남은 어려움을 확인하고 분량과 지원을 조정하는 방법을 안내합니다.

작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

계획을 못 지켰다는 말만 남기지 말고 실제로 끝낸 것과 남은 이유를 적으세요. 목표·분량·자료·도움 중 무엇을 바꿀지 정한 뒤 작은 과제로 다시 확인합니다.

현재 상태 확인

  • 계획한 결과와 실제 결과를 비교했나요?
  • 미완료가 난도·일정·준비 중 무엇 때문인가요?
  • 바꾼 계획을 확인할 과제가 있나요?

실행 순서

  1. 원래 목표 읽기

    혼자 설명하거나 수행하려던 행동을 확인합니다. 목표가 모호했다면 실제 결과로 바꿉니다.

  2. 실제 결과 모으기

    완성한 답안·풀이·기록과 도움받은 부분을 봅니다. 공부시간만으로 완료를 판단하지 않습니다.

  3. 원인과 수정 연결하기

    분량 문제는 범위를, 개념 문제는 설명과 적용을, 일정 문제는 배치를 조정합니다.

  4. 작은 과제로 확인하기

    바꾼 조건에서 실행하고 실제 결과를 기록합니다. 효과가 없었다면 원인 판단을 다시 살핍니다.

연습 예시

연습 예시: 영어 본문 복습이 계속 밀렸다면 자료가 없었는지, 단어가 막혔는지, 시간이 부족했는지 나눕니다. 단어가 원인이면 필요한 표현을 먼저 확인한 뒤 본문 설명 과제로 돌아옵니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.

학부모가 도울 일

실행 자료를 함께 보고 학생이 수정 이유를 말하도록 돕습니다. 지키지 못한 계획을 그대로 더 크게 만들지 않습니다.

놓치기 쉬운 점

계획 수정이 과제의 실제 제출 조건을 바꾸지는 않습니다. 마감 조정이 필요하면 담당자에게 확인합니다.

다음 확인

바꾼 계획에서 목표 행동을 혼자 하는지 봅니다. 시간이 줄었다는 이유만으로 이해가 나아졌다고 단정하지 않습니다.

매번 계획을 바꿔도 되나요?

무엇부터 줄일까요?
