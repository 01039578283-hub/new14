중등고등학생학부모

온라인 강의와 AI 학습을 이용한 뒤 자신의 수행과 답변의 근거를 확인하는 방법을 안내합니다.

작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

시청 완료나 AI의 설명만으로 학습을 마쳤다고 보지 마세요. 자료를 닫고 직접 해본 결과를 남기고, AI가 제시한 사실과 풀이를 교재·공식 자료에 대조합니다.

현재 상태 확인

  • 도구 없이 설명하거나 문제를 풀어봤나요?
  • 답변의 출처가 실제로 내용을 뒷받침하나요?
  • 과제의 도구 사용 규칙을 확인했나요?

실행 순서

  1. 목표 정하기

    개념 설명·연습·답안 검토 중 필요한 도움을 고릅니다. 학교 과제의 허용 범위를 확인합니다.

  2. 짧게 보고 시도하기

    필요한 강의 구간이나 설명을 확인한 뒤 닫고 직접 수행합니다. 복사한 답과 자신의 풀이를 구분합니다.

  3. 근거 대조하기

    AI의 계산·인용·사실은 교재와 공식 자료에서 확인합니다. 링크가 있다는 이유만으로 맞다고 판단하지 않습니다.

  4. 남은 질문 정하기

    틀린 내용과 혼자 못 한 부분을 적고 교사에게 확인할 질문을 만듭니다.

연습 예시

연습 예시: AI가 제시한 수학 풀이를 받았다면 각 식이 같은 값을 유지하는지와 조건이 빠지지 않았는지 확인합니다. 설명을 닫고 문제를 다시 풀어보고 막힌 줄을 남깁니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.
