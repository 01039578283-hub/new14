중1 학생이 학교의 평가 범위와 과제 조건을 확인하고 준비할 일을 나누는 방법을 안내합니다.

작성·내용 확인: 2026년 10월 4일

먼저 해볼 일

시험 경험이 적을수록 문제집을 먼저 정하기보다 학교 안내를 읽는 일이 필요합니다. 평가 범위, 답안 방식, 제출 조건을 서로 다른 칸에 옮겨 적으세요.

현재 상태 확인

  • 범위가 교과서·수업 자료 중 어디에 해당하나요?
  • 지필평가와 수행평가의 할 일을 구분했나요?
  • 안내에 없는 내용은 확인할 질문으로 남겼나요?

실행 순서

  1. 출처 적기

    학교나 교사가 제공한 안내의 제목·날짜를 적고 변경 안내가 있는지 확인합니다.

  2. 범위를 펼치기

    단원명만 적지 말고 교과서 페이지와 수업 자료를 연결합니다. 아직 배우지 않은 부분은 따로 표시합니다.

  3. 요구 동사 찾기

    설명·비교·계산·제출처럼 학생이 해야 하는 행동을 표시합니다. 답안을 어떤 형태로 남길지도 씁니다.

  4. 연습 결과 정하기

    읽었다는 표시 대신 설명 한 문장, 재풀이 한 문제, 완성한 초안처럼 확인할 결과를 정합니다.

연습 예시

연습 예시: “두 개념을 비교해 쓰기”라는 안내가 있으면 개념 이름 외에 공통점과 차이점이 들어간 답안을 연습합니다. 학교가 제시한 배점과 분량은 실제 안내에서 옮겨 적습니다.

이 활동은 직접 연습하기 위한 예시이며 실제 학생의 사례가 아닙니다.

학부모가 도울 일

시험 범위를 대신 외워주기보다 아이가 필요한 자료를 찾는 과정을 도와주세요. 모호한 조건은 학교에 확인할 질문으로 만듭니다.

놓치기 쉬운 점

다른 학교의 기출이나 인터넷 후기를 학교의 확정 범위처럼 사용하지 않습니다. 바뀐 안내가 있으면 계획도 고칩니다.

다음 확인

계획표의 각 항목에 대응하는 자료와 결과물이 있는지 확인합니다. 빠진 범위보다 어려워서 미룬 부분을 먼저 찾습니다.

문제집을 다 풀어야 준비가 되나요?

범위와 답안 요구를 연습할 수 있는지 먼저 살펴보세요. 분량만으로 준비 상태를 판단하기 어렵습니다.

수행평가 준비도 같은 표에 넣나요?

같은 일정표에 넣되 제출물·중간 확인·시험 연습은 구분해서 적습니다.
