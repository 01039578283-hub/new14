과제·복습 루틴과 개념 설명·적용: 주간 계획·시작·완료·질문 기록과 개념 설명 메모·대표 문제의 선택 이유는 어떻게 나눠 확인하나요?

과제·복습 루틴: 주간 계획·시작·완료·질문 기록에서 ‘할 분량과 도움받을 항목을 나누어 기록하기’를 실행하고 완료 여부·미완료 이유·조정한 분량을 남기세요. 개념 설명·적용: 개념 설명 메모·대표 문제의 선택 이유에서 ‘같은 기능의 짧은 문제를 다시 해 보기’를 실행하고 새 문제에서 개념을 고르고 사용 이유를 설명한 범위를 적습니다. 두 결과는 각각 해당 자료의 첫 기록과 비교하세요.

상담 전 계산 과정·검산과 문장제 조건·식 세우기를 확인하려면 어떤 자료를 가져가나요?

계산 과정·검산은 ‘오류가 처음 시작된 계산 줄, 답을 고친 뒤 다시 쓴 과정과 검산 표시’, 문장제 조건·식 세우기는 ‘밑줄 친 조건, 처음 그린 그림과 세운 식에서 빠뜨린 정보’가 남은 최근 자료로 확인하세요. 이어 ‘정답 풀이를 보여 주기 전에 아이가 조건을 식으로 바꾸는 과정을 어떻게 살피는지’를 묻고 확인일을 정합니다.

미아동 초등 수학 상담에서 가능 학년과 참고 학교는 어떻게 확인하나요?
